One-Liner Marathon entry on make.fun by itslanaa.

The program writes a single one-line joke (154 characters, within the 280-character limit) to `/output/entry.txt`:

> I asked my AI agent for a one-line joke, and it gave me a 280-character essay, a bibliography, and a follow-up question about whether the essay was funny.

Run it with `node main.ts`. Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
